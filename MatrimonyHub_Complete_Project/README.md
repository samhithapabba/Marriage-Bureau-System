# MatrimonyHub - Marriage Bureau System

Frontend-only marriage bureau management system built with HTML5, CSS3 and JavaScript.

## Features
- Dashboard with statistics
- Client registration with 4-step form
- Client directory with search and filters
- Client profile view/edit/delete
- Preference-based matchmaking compatibility score
- Inquiry management
- Internal simulated messaging
- Success stories
- Reports and analytics
- CSV export
- Login simulation
- Dark mode
- Responsive mobile layout
- localStorage persistence

## Run
Open `index.html` in a modern browser. No server or database is required.

Data is stored in browser localStorage. Clearing browser site data resets the application to the sample data.
